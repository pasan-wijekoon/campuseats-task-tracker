# CampusEats Task Tracker

## Overview

CampusEats Task Tracker is a small repository created to demonstrate a professional software development workflow using Git and GitHub.

The project focuses on:

* Version control with Git
* Feature branching
* Pull requests and code review
* GitHub Issues for task tracking
* Continuous Integration using GitHub Actions
* Code quality and secure development practices

## Project Purpose

The purpose of this project is to practise a real-world team workflow:

**Branch → Commit → Pull Request → Review → Merge**

The repository represents a small task-tracking component for the CampusEats project. It contains a simple task list rather than a complete application so that the main focus remains on collaboration, automation, quality, and security.
